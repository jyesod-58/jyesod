# 2.0.0 변경 내역

- 개인정보 후보와 사람의 정탐·오탐 판정을 분리하고 최초 상태를 확인 필요로 변경.
- 원거래 전부 보존, 메서드·상태·시각·요청 보존, 응답/파일 SHA-256 연결.
- 항목 단위 압축·문자셋 해독, 손상 항목 격리, 미분석 회계와 상한 추가.
- 헤더·스크립트·속성·XML·정적 텍스트 검사 영역 확장.
- 키 정규화, 전화·카드 규칙, 계좌·여권·면허 전용 필드 후보 보완.
- 프로젝트 저장·복원, 원문 없는 마스킹 JSON 보고서 추가.
- 상세 마스킹 상속, 원문 공개·복사 확인, 주민번호 마스킹 강화.
- 로컬 gzip/deflate/Brotli(선택 패키지) 변환 도구와 합성 XML 예시 추가.
- 크롤러 거래 중복 삭제 제거, 승인 호스트 범위 제한, 문자셋 보존과 비밀정보 마스킹 보완.
- 로컬 서버 인증·Origin/Host·요청 크기/형식 검사와 안전한 다운로드 추가. 크롤러 패키지 지연 로딩.
- 승인 범위 보호를 위해 크롤러 HTTP 리다이렉트 차단. LLM 추출은 제공하지 않음.

의도적으로 남는 범위: PDF/OCR·Office 추출, 모든 개인정보 유형의 식별, 접근권한/취약점 확정, 원문 프로젝트 자체 암호화는 제공하지 않습니다. 처리 한도와 미지원·실패 항목을 확인하고 기관의 보관·점검 절차를 적용하세요.
