개인정보 응답 검토기 2.1.0 — Burp HTTP history용

1. ZIP 압축을 모두 풉니다.
2. pii_finder.html을 최신 Chrome/Edge로 엽니다. 설치 불필요.
3. Burp HTTP history의 Save selected items XML(응답 포함)을 넣습니다.
   Burp XML은 파일당 500MiB까지 지원합니다. 큰 파일은 임시 저장에 동의하세요.
4. 분석 범위를 펼쳐 실패/미지원/일부 검사/제외를 확인합니다.
5. 직접 검토 판정 후 프로젝트 또는 마스킹 보고서를 저장합니다.

sample_burp.xml은 가상 데이터로 만든 동작 예시입니다.
프로젝트는 원문 포함 평문 민감자료입니다. 승인된 위치에 보호하세요.
Brotli 변환/한도/미지원 자료/선택 크롤러 사용법은 README.md 참조.

대용량 원문은 브라우저에 평문으로 남을 수 있습니다. 검토 후 임시 원문 전체 삭제를 실행하세요.
