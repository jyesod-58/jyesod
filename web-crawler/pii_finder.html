분석 범위와 미완료 응답

프로젝트는 원문과 검토 판정을 로컬 JSON으로 저장합니다. 원문 프로젝트는 기관의 보관 정책에 따라 보호하세요. 마스킹 보고서에는 응답 원문을 넣지 않습니다. 자동 탐지는 개인정보 노출 취약점의 확정 판정이 아닙니다.

응답 데이터 불러오기

Burp XML은 파일당 500MiB까지, JSON/HAR/텍스트는 100MiB까지 가져옵니다. 25MiB 초과 파일은 브라우저 임시 저장소를 사용합니다. 필드에 담긴 값에서 민감정보를 찾습니다(필드 이름은 탐지 단서로만 사용). 여러 파일을 한 번에 선택하거나 이 페이지로 끌어다 놓으세요. 기존 결과는 유지하고 새로운 응답만 누적 분석합니다. 동일 응답도 원거래별로 보존하며 결과 표시만 선택적으로 묶습니다. 전체를 비우려면 클리어를 누르세요. 모든 분석은 이 브라우저 안에서만 이뤄지며 데이터는 외부로 전송되지 않습니다.
· Burp XML — Site map 또는 Proxy HTTP history에서 Save selected items로 저장(응답 포함)
· HAR — 응답 내용이 포함된 HAR 파일
· results.json — 크롤러가 만든 수집 결과(본문 포함)
· 또는 JSON·응답 텍스트를 아래에 직접 붙여넣기

‘정적 리소스 제외’와 ‘체크섬 실패 제외’는 무슨 뜻인가요?

정적 리소스 제외 — 웹사이트의 이미지·글꼴·화면 꾸미기·동작 코드 등을 선택하면 검사에서 뺍니다(기본은 검사). 코드 속 숫자와 예시 문구를 개인정보로 잘못 잡는 일을 줄입니다. 끄면 코드 속 값도 검사하므로 결과와 처리 시간이 늘 수 있습니다.

체크섬 실패 제외 — 일부 식별번호·카드번호에 정해진 계산 규칙을 적용하고, 그 규칙에 맞지 않는 결과를 숨깁니다. 규칙에 맞아도 실제 번호라는 보장은 없고, 틀려도 테스트값이나 발급 체계 차이일 수 있습니다. 처음에는 꺼두고 원문을 확인하세요.

모든 자동 탐지는 최초 ‘확인 필요’입니다. 개인정보 문자열의 존재와 권한 없는 노출 취약점 여부는 별도로 검토하세요. 후보와 텍스트 응답도 기본 검사하며 PDF·이미지 등 미지원 자료, 해독 실패·제한 도달 항목은 분석 범위에 표시합니다. 계좌·여권·면허는 전용 필드와 형식에 따른 후보로 실제 발급·유효성·소유자를 검증하지 않습니다. 요청 URL과 응답의 발견을 구분합니다. HTML·코드는 실행하지 않고 텍스트로 검사합니다. 목록 마스킹은 상세에도 적용되며 원문 공개·복사는 별도 확인을 거칩니다. 프로젝트는 원문을 포함한 평문 파일이므로 승인된 위치에 보호하여 보관하세요. 마스킹 보고서도 공유 전 검토해야 합니다.

상세 마스킹을 켠 상태입니다. 해제하면 응답 원문을 다시 표시합니다.
